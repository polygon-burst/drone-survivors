Drone Survivors P-TYPE ( WORK IN PROGRESS )

( In this version: The 0xF shades of EGA_PALETTE_GREY )

There are some artificial limitations in this proto-prototype:
- The music files* are in Amiga .MOD format (by martincameron's Micromod)
- The graphics are just lines and polygons (by earlgrey's ShapeDrawer)
- The color palette is EGA-like, just with transparency (by my little hands)

( *Regarding the music files themselves, I found this. )

Desktop versions:


The Main controls are as follows:
- Mouse Left Button: Select, Increase
- Mouse Right Button: Decrease
- Keyboard Arrow Keys / Controller DPad, Analog Stick : Step, Increase/Decrease
- Keyboard W, D, Enter Key / Controller A, X, R1 Button : Ok, Increase
- Keyboard S, A, Backspace Key / Controller B, Y, L1 Button : Cancel, Decrease
- Keyboard Escape, Space Key / Controller Start, Back Button : Settings, Back

Game controls:
- Keyboard Arrow Keys / Controller DPad, Analog Stick : Movement
- Keyboard W, Enter Key / Controller A : Emulate Magnet pickup (with auxiliary healing)
- Keyboard S, Backspace Key / Controller B Button : Emulate Freeze pickup
- Keyboard A Key / Controller X, L1 Button : Rotate left
- Keyboard D Key / Controller Y, R1 Button : Rotate right
- Keyboard Escape, Space Key / Controller Start, Back Button : Overview
- Keyboard F1 : Debug draw
